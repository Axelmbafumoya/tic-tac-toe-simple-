# 🎮 Tic-Tac-Toe

A simple and interactive **Tic-Tac-Toe game** built with **HTML, CSS, and JavaScript**.

## 📸 Preview

![Tic-Tac-Toe Preview](./assets/preview.png)

## 📌 About the Project

This project is a classic **two-player Tic-Tac-Toe game**.

Players take turns placing their symbols (**X** or **O**) on a 3×3 grid. The first player to align **3 identical symbols** horizontally, vertically, or diagonally wins the game.

The project was created to practice **JavaScript game logic, DOM manipulation, event handling, and user interactions**.

## ✨ Features

- 🎮 Two-player gameplay
- 🏆 Automatic win detection
- 🤝 Draw detection
- 🚫 Prevents moves after the game ends
- 🔄 Reset button to start a new game
- 🎉 Confetti animation when a player wins
- 🔊 Sound effects for player actions and victory
- 📱 Responsive design

## 🛠️ Technologies

- **HTML5** — Page structure
- **CSS3** — Styling and responsive layout
- **JavaScript** — Game logic and interactions
- **Canvas Confetti** — Victory animation

## 🎮 How to Play

1. **Player X** starts the game.
2. Players take turns choosing an empty cell.
3. Align **3 identical symbols** horizontally, vertically, or diagonally to win.
4. If all cells are filled without a winner, the game ends in a **draw**.
5. Click the **Reset** button to start a new game.
